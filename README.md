# Cloak

Cloak records privacy-preserving eligibility commitments and nullifier checks. This repository contains the verified `CloakVerifier` contract and its Foundry tests.

Testnet deployment and explorer proof: [BOTCHAIN_TESTNET.md](BOTCHAIN_TESTNET.md).

This repository publishes the contract layer only. It does not include a production prover or claim a live issuance workflow, public web app URL, or mainnet deployment.

```sh
forge build
forge test
```
